# MOMO 智能画布

一款以「智能画布」为核心的 AI 创作工作站。单一画布范式：把图片、提示词、对话、生图、视频、ComfyUI 工作流都变成画布上的节点，连线即工作流。

> 技术栈：Tauri 2 (Rust) · React 19 · TypeScript · React Flow (@xyflow) · Zustand
> 目标平台：Windows（主）/ macOS（后续分发）

## 启动

```bash
pnpm install
pnpm tauri dev      # 开发调试
pnpm tauri build    # 打包发行（需明确要求时再执行）
```

## 功能地图

| 模块 | 说明 |
| --- | --- |
| 智能画布 | 输入（图片/视频/音频/提示词/风格预设/备注）· 智能（拼接文本/分镜）· 生成（生成图像/生成视频/生成音频/ComfyUI）· 编辑（打光/多角度，图片直接编辑走节点工具条：裁剪/重绘/扩图/尺寸/增强）· 视频（取帧/取段/拼接·时间线/配音）· 角色（角色卡）。对话与文本处理已并入右侧创作助手与提示词工具弹窗 |
| 画布模板 | 组一键存为模板（配置+连线），Ctrl+K / 双击菜单反复实例化；内置 4 套示例工作流播种画布 |
| AI 布线助手 | 工具栏魔棒：一句话生成连好线的工作流，方案先预览、确认才落画布 |
| 模型配置 | **服务商卡片**：一张卡 = 一个中转站/官方（Base URL + Key 只填一次），下设对话/绘画/视频/音频/语音识别五类槽位，每类可加多个模型；顶部「默认模型」五类各选一个，节点/助手不单独指定时全用它 |
| 多协议 | 对话：OpenAI 兼容 / Anthropic Claude / Google Gemini；绘画：OpenAI images / Gemini 生图；视频：智谱 / 硅基流动 / OpenAI 任务式；音频：OpenAI `/audio/speech`；语音识别：OpenAI `/audio/transcriptions`（本地 FunASR 服务同样兼容） |
| 资产库 | 独立模块：画布生成内容自动落盘收录；同一次多图生成自动折叠为叠放组卡，点击后聚焦展开（电商切片与最终长图同组）；分类分区、文件夹、标签、条件筛选、批量删除/移动/打标签；缩略图卡片 + 原分辨率预览（图片/视频/音频/PDF）；图片卡片可直接拖回画布变成图片节点 |
| 创作助手 | 右侧边栏，取代原对话节点：**聊天**（多模态、可拖入图片/视频/文字、上下文自动压缩、一键在画布生图）+ **Agent**（自动搜资料 → 抉择确认 → 出图出片 → 发到画布）；顶部一行直选对话/绘画/视频模型 |
| 语音 | 语音输入（说一句转文字）与**语音通话模式**：VAD 自动断句 → 识别 → 助手回复 → TTS 朗读 → 自动续听，说话即可打断朗读 |
| 联网搜索 | Tavily / 博查 / SearXNG；模型自带联网（GLM / MiniMax / 混元等）优先走模型自己的搜索，失败自动降级 |
| 图片保存 | 保存目录、PNG/JPG/WebP、命名模板、生成后自动保存（独立于资产库收录） |
| ComfyUI | 直连本地服务；模板编辑器为**中文节点示意图**（连线关系可视、图/文入口与输出自动识别标记、可忽略节点/改输出/改默认值）；运行时上游图片自动喂给 LoadImage（缺图片入口时自动注入）、提交前按 object_info 校验并给中文报错；WebSocket 实时节点级进度条 |
| 生成记录 | 会话内时间线（右侧坞），完整历史在资产库 |
| 运行日志 | 标题栏活动图标：每次对外请求的方法/状态/耗时/请求体/响应体（密钥脱敏、轮询合并），排查中转站问题第一入口 |
| 批量出图 | 生成设置面板「批量出图」：一行一条提示词并行克隆生成；另有多模型对比 |
| 提示词历史 | 生成成功自动收录，提示词/生成节点上一键回填，支持搜索与收藏置顶 |
| 自动更新 | 设置→关于与更新：安装版走签名更新包自动安装，便携版下载 zip 自动替换重启；启动后台静默检查 |
| 主题 | 云白 / 深空蓝 / 深邃黑，标题栏或 Ctrl+Shift+T 一键切换 |

## 画布操作

| 操作 | 方式 |
| --- | --- |
| 平移 / 缩放 | 中键/右键拖拽 或 Space+左键；滚轮缩放 |
| 框选 | 左键拖拽空白处；Shift/Ctrl 加选 |
| 添加节点 | 双击空白 · 底部工具坞点击/拖放 · 从输出端口拖线到空白处 |
| **贴近自动连线** | 把节点拖到另一节点的左/右侧贴近（≤90px 且纵向有重叠）松手，自动按端口类型连线 |
| **拖线强吸附** | 从端口拖出连线，松手落在目标节点身上任意位置即自动接到匹配类型的端口（从输入口反向拖到上游节点同样生效），不必对准端口点 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y（右下角也有按钮） |
| 搜索节点 | Ctrl+F：按名称/提示词/内容搜索，回车飞越并选中 |
| 快速添加 | Ctrl+K：Spotlight 键盘流搜索节点/画布模板并插入 |
| 导入图片/视频 | 拖入文件（图片、mp4/webm/mov 等视频）/ Ctrl+V 粘贴图片 / 节点上点击导入；视频自动落进资产库拿持久地址 |
| 复制 / 删除 | Ctrl+D / Del；适应全部：F；沉浸模式：Tab |
| **Alt 拖拽复制** | 按住 Alt 拖节点 = 复制一份跟手走，原节点不动；多选后 Alt 拖整组复制且保留内部连线 |
| **对齐吸附** | 拖动时自动吸附到其他节点的边/中线并显示参考线；A 键把所选节点强制对齐 |
| 前后对比 | 编辑类节点（重绘/扩图/抠图/增强/打光/多角度）点开大图后「对比原图」拖分割线擦看 |

## 数据流转规则

- 端口已统一（不再按类型拒连）：任意输出可接任意输入，实际传什么由源节点的输出类型决定；防环与重复边仍会拦截。
- 生成节点提示词留空时，自动取上游文本（提示词/分镜/拼接/风格预设等）。
- 拼接文本会递归物化其上游；风格预设输出选中片段的英文串。
- 生成节点连接上游图片时自动转为图生图（ComfyUI 依次填入图片参数并自动上传）。
- 每个生成/智能节点可在节点上单独选择模型卡片，默认跟随「设置 → 模型配置」中的单选默认。

## 数据存放

- 设置 / 画布 / 模板 / 资产索引 / 面板参数记忆（`gen-prefs.json`）/ 助手模型选择（`agent-prefs.json`）：AppData（tauri-plugin-store JSON）。
- 资产文件：`AppData/site.jinpengi.momo/assets/`（缩略图在 `assets/thumbs/`），删除资产会同步删除磁盘文件。
- 本地超清模型（ONNX）：**必需 8 个（~230MB）内嵌安装包**（`bundle.resources` 释放到 exe 同级 `models/`，便携 zip 同样附带），开箱即用；可选模型（GFPGAN/CodeFormer 各 ~350MB）按需下载到 `AppData/models/`。运行时解析顺序：AppData 副本 > 内嵌 > 自动下载（下载带 SHA-256 校验）。
- API Key 以明文存本机配置文件，请勿把 AppData 目录同步到公共位置。
- **密钥不进安装包**：所有配置只在本机 AppData，分发安装包/便携包给他人时对方是全新空白配置。
