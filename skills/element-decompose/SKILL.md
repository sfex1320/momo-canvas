# 元素拆解

先识别输入图中的独立元素，提供可核对的名称、可见文字与范围。在 MOMO 中使用图片「元素工坊」的框选清单，允许用户拖动修正、圈选新增、改名与取消勾选。

按用户指定选择正面、背面或底面。未指定时用正面，不擅自一次生成三套。正面去除透视、挤出厚度、投影和空间背景，保留轮廓、比例、图案和文字。背面、底面不可见部分只能依照用户说明推定，标明「推定，待核对」。不能把模型猜测当成真实内部结构或测量结果。

使用原图和该元素局部截图作绘画模型参考，每个元素单独请求。中文、标志与专有图案保持原样，不让模型自行补写。背面颜色、底面颜色和最终背景分别控制。透明稿先采用显著色键背景，再清理边缘；纯色背景在最终画板上合成，避免把模型声称的透明背景直接当作真实透明通道。

尺寸表示输出画板，不代表模型推测出了实物尺寸。像素尺寸直接使用；毫米按 `px = round(mm × DPI / 25.4)` 换算。缺尺寸可先用 1024×1024 px。保持元素宽高比，不用拉伸填满画板；超出运行环境安全尺寸时提示减小尺寸或分块。MOMO 当前上限为单边 8192 px、总量 2400 万像素。

调用已配置的绘画模型，先展示模型、件数、视图、输出像素与费用估算。严格遵守预算，不自动更换计费模型、不自动重试已成功元素。把生成图存入资产库，再建立独立图片节点，记录来源、元素名、视图和尺寸。部分失败保留已成功稿，仅重试未完成项。

交付检查：元素是否完整、无透视、无残余色键边缘；文字是否逐字一致；实际图片像素是否等于目标值；背面/底面是否标明推定。单张图不能提供可信的刀模、装配公差、内部结构与真实物理尺寸；需要这些成果时，应依据人工尺寸和矢量路径继续制作。
