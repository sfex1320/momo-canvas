# 海报工具整合与第一轮实测

本轮结论：MOMO 适合沿现有「画布节点 + 图层组」继续整合。推荐优先验证的组合是：**整图生成 → 视觉识别初稿 → 人工校准范围和原文 → 主体蒙版初稿 + 标记精修 → 按需重绘单个元素 → 原位合成 / PSD**。自动识别框直接裁切、自动抠图直接交付，两条捷径在本轮真实样例上都出现明显问题。

这是一张简单产品海报的第一轮实测，不能据此宣称所有海报均可自动还原。Qwen-Image-Layered 及其封装路线按用户要求排除。

## 功能入口整合

| 位置 | 入口 | 说明 |
|---|---|---|
| 创作 | 元素 | 识别、校准、抠图、拆解或逐元素重绘 |
| 创作 | 高清 | 统一入口，内部区分「本地放大」和「模型重绘」 |
| 创作 | 局部重绘 | 涂选区域修改 |
| 创作 | 创意模板 | 分镜、机位、设定图 |
| 整理 | 裁剪 / 切图 / 扩图 / 标记 | 常用编辑工具 |
| 更多工具 | 尺寸 / 矢量 / 平面稿 | 低频工具；平面稿标实验功能并默认收起 |

重复的矢量入口合并；元素编辑中暂时隐藏单件视图重绘入口。精修抠图中的 U2NetP 按钮收进「自动初稿」，不再暗示一次自动计算就是最终蒙版。图标继续使用现有手绘 SVG 系统，海报、绘画、镜头、工具箱使用不同图形。

风格预设共新增或扩充为 **22 种海报、28 种绘画、32 种镜头与构图预设**。海报按版式、商业、文化、实验分组；镜头按景别、视角、光学、构图分组。增加搜索、中文已选项和单项移除，保留旧分类键与原有提示词值，已有节点可继续使用。

## 真实服务与蒙版对比

海报由已配置的 apilio.ai / gpt-image-2 生成，1024×1536；识别使用 MiniMax-M3。图片为本轮自制测试样例：奶油色底、红杯、白色杯身印花、中文标题和太阳装饰。

| 测试 | 实际结果 | 判断 |
|---|---|---|
| 整张海报生成 | HTTP 200，约 32.4 秒收到响应，标题实际为「春日上新」 | 单次生成成功 |
| 视觉识别 | HTTP 200；漏读标题中的「日」，框与文字位置有偏差；将杯身印花、太阳圆心分别拆出 | 只能作为初稿，需校准和去重 |
| 识别框直接裁切 + 色键 + 本地补底 | 生成图层，但合成中标题出现明显残留重影 | 不适合一键交付 |
| 第二次单主体高清重绘 | 流程返回失败，代理未记录到有效重绘 HTTP 响应 | 不能判定重绘质量通过；本轮不追加付费重试 |
| U2NetP 自动蒙版 | 杯身白色印花被挖空 | 不能作为最终结果 |
| 人工标记 + GrabCut | 白色印花保留，把手孔透明，但底部有阴影残留 | 比直接自动抠图可控，仍需复核 |
| U2NetP 初稿 + 相同人工标记精修 | 印花保留，把手孔透明，底部残留较少 | 本样例中最合适的蒙版组合 |

本地三种蒙版使用相同的人工校准裁切范围 `[250,805,880,1320]`。两个需要标记的方案使用相同标记。印花中心 alpha 对比为 0 / 255 / 255，把手孔和左上角均为 0。采样点仅验证关键错误，不能替代全图质量评分；轮廓仍存在锯齿或浅边，复杂毛发、半透明玻璃尚未覆盖。

样例、失败基线和本地对比图保存在 `.codex/poster-acceptance/`；该目录是本机验收产物，不随代码上传。`report.json` 记录真实服务结果，`local-report.json` 记录蒙版采样结果。

## 已修复的流程问题

1. **高清层拼回低分辨率**：图层组增加原尺寸 / 2 倍 / 4 倍输出；新建高清拆解组默认 2 倍，老图层组保持原尺寸。
2. **PSD 位置与预览不一致**：合成和 PSD 共用整数像素定位及缩放，高清源层不会再按自身像素尺寸撑出原框。
3. **更换背景导致尺寸漂移**：新图层组保存原海报尺寸；放大或移除背景后，仍使用原海报坐标基准。
4. **白色高光被色键误删**：主体默认只删除边缘连通的背景色；文字保持字腔抠图方式。该修复不能解决全部同色相连物体或封闭孔洞，仍可用精修蒙版。
5. **文字重绘提示词互相冲突**：明确传入并保留原文；元素窗口增加「校对原文」，重叠框提供提醒。

输出最长边限制为 8192 像素，总像素限制为 2400 万。倍率定义输出尺寸，不能凭空增加原图细节。图层节点的卡片位置用于工作流组织；合成坐标仍来自元素框，移动卡片不等于改变海报排版。

当前 PSD 的文字仍是位图层。「改字」调用模型重绘，不是原生字体编辑。本轮没有实现字体识别或原生文本层，也没有把未完成的重绘服务测试算作通过。

## 开源项目选择

| 项目 | 与 MOMO 的关系 | 本轮处理 |
|---|---|---|
| [Image To Slice](https://github.com/50kg/image-to-slice) | MIT；提供识别、人工校准、遮挡背景补齐、按坐标输出等流程，主要面向 UI 还原 | 最值得借鉴流程，不直接嵌入另一整套编辑器；没有对该项目做推理质量实测 |
| [Hi-SAM](https://github.com/ymy-k/Hi-SAM) | 分层级文字分割，可作为艺术字蒙版候选；本身不等于 OCR 或原生文字节点 | 待专项测试中文标题、细字和字腔，本轮未部署 |
| [Grounded-SAM-2](https://github.com/IDEA-Research/Grounded-SAM-2) | 目标检测和分割组合，适合主体识别与蒙版候选 | 待与现有轻量蒙版比较，不能代替背景重建或字体恢复 |
| [LayerD](https://github.com/CyberAgentAILab/LayerD) | 图形设计分层研究项目，提供设计元素拆解路径 | 作为研究候选；本轮未部署，不能凭演示判定更优 |

以上项目均不代表「高清重绘每个元素 + 无损恢复整张海报」的完整现成答案。当前更适合 MOMO 的产品形态是复用一个元素工作区，按步骤替换识别、蒙版、补底和重绘实现。
