# Codex 会员桥接与平面拆件交付

## 使用入口

1. 设置 → 模型配置 → Codex 会员生图 → 检查连接与额度。用 Codex 的 ChatGPT 登录，不填 API Key。可选择本机 codex.exe，或设为默认生图。
2. 画布、创作助手、效果图转平面总稿、单件重绘共用绘画模型选择。选择「Codex 生图」后生成结果按现有资产管线回画布。
3. 将上一张 Codex 结果作为参考图继续修改，自动恢复原会话；生成节点「新会话」可关闭历史继承。同一原生后台退出后仍可继续，图片像素指纹与会话关联保存在 AppData 的 codex-image-bridge 目录。
4. 每次 1 张，通道串行排队；可停止。在途停止会发 turn/interrupt 并回收 MOMO 自己启动的进程。停止前已提交的远程计算仍可能计入额度。
5. 图片会员额度与 API 金额预算分开。额度面板显示剩余百分比和恢复时间，不把会员换算成现金余额。不会自动重试、切付费备用模型、买额度或兑换重置券。

Codex 桌面窗口无需一直开着，MOMO 按需启动官方 app-server。MOMO 本身在生成期间应保持运行。本机 stdio 桥不经过网络，但 Codex 仍需连接 OpenAI 服务；沿用进程网络环境，不自动安装或切换 VPN。若已经可以在 Codex 中正常生图，优先使用相同网络环境。

## 拆件制作流程

效果图 →「效果图转平面总稿」→「元素抠图与分层」逐件拆出 → 对有问题的单件用「高清增强 / 平面拆件清理」重绘核对 →「平面拆件清理与矢量」→ SVG / PDF / 高清 PNG。

- 绘画模型负责去透视、平面化和局部重绘。语义重绘结果仍是栅格图，不能把“矢量风格”当成真正的矢量文件。
- 本地平面模式做 2–64 色聚类，整理压缩噪点和近似色，保持像素位置与 alpha；适合纯色美陈、文化墙、Logo。色数太低会合并相近颜色，应在预览中核对。
- 平面模式采用轮廓折线，避免样条拟合把矩形直边拉成鼓包。圆弧由轮廓细分近似，仍是可编辑的矢量路径；几何拟合可另行开启。
- PDF 由本地 SVG 转 PDF 库独立导出，保留路径与毫米尺寸，无需 Illustrator。严格矢量 PDF 拒绝位图和滤镜。
- PNG 从矢量路径重新渲染，支持 1/2/4/8 倍，最多 6400 万像素；不会对原图马赛克再做插值放大。SVG/PDF 不需要先放大到 4K/8K 才能打印。
- 图片矢量化后是否与原图相似，只代表描摹一致性；不证明文字、结构、刀模或尺寸在工程上正确。

## 能力边界

Codex 桥接当前实现一轮一图与参考图连续修改；不支持像素蒙版约束，多张需要逐张任务。目标尺寸属于提示要求，本次请求 1024×1024 实际返回 1254×1254，界面/导出读取真实尺寸，不伪称固定像素。

本次用简单图形验证通道与轮廓修复，不能代表任意复杂美陈的文字识别、遮挡推理和工程准确度都已通过。SeedVR2 未在本轮安装或做同图 A/B 对比；已有 ComfyUI 通道仍可接相应工作流，纹理类素材适合单独比较，纯色拆件优先用清理→矢量→渲染。

前序全协议、真实语音及长期重负载验收不因此扩大为“全部通过”，此前报告中的范围和限制仍适用。
