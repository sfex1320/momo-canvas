# 快捷键补全（2026-09-19）

近期入口新增六组默认快捷键，均在画布工作区、焦点不在输入框且没有遮挡弹层时生效。导演台继续使用原有工作区按键；`Ctrl+Shift+D` 保留为导演台开关。

| 功能 | 默认键 | 行为 |
| --- | --- | --- |
| 一键启动 ComfyUI | Ctrl+Shift+C | 复用顶部启动按钮的 `launchComfy`；正在启动、正在选择启动器或已连接时不重复执行 |
| Comfy 工作流同步中心 | Ctrl+Shift+S | 打开已有同步中心 |
| ComfyUI 模板管理 | Ctrl+Shift+M | 打开已有模板管理器 |
| Skill 管理 | Ctrl+Shift+K | 打开已有 Skill 管理器 |
| 所选图片加入创作助手 | Ctrl+Shift+I | 与右键、拖入共用入口；组选图按阅读顺序展开，父子多选去重，读取当前选中结果 |
| 模型配置 | Ctrl+Shift+U | 打开设置中的模型配置页 |

设置仍使用 `Ctrl+,`；原有画布、节点添加、助手和导演台绑定保留。此次没有为清显存、删除记录等低频或有副作用的按钮新增默认绑定。

## 自定义与迁移

- 设置 → 快捷键按功能列出新增项；点击键帽录制，Esc 取消，“解绑”保存为空值。
- 设置加载和配置导入都经过 `normalizeHotkeys`。保留已有字符串绑定和明确解绑；缺失项补默认键，默认键若与已有自定义在同一作用域冲突则保持未绑定。
- 已停用的人物预设、旧对话节点、旧文本处理节点快捷键清空，不能占用新默认键。
- 冲突检测区分画布与导演台作用域；导演台开关在两个作用域都生效，因此仍参与两边的冲突检测。
- 恢复默认会重置全部自定义快捷键，这是明确点击该按钮才发生的操作。

## 防误触与验证

画布快捷键跳过输入框、可编辑区域、输入法组词、已被其他界面消费的事件，以及长按产生的重复事件。设置、模板、同步中心、Skill、灯箱、媒体编辑等浮层打开时不操作背后的画布。删除也统一经过这层保护，再调用 React Flow 的节点/连线删除入口；关闭库的独立按键监听，取消旧版始终生效的 Backspace 别名。默认仅 Delete 删除；若需要 Backspace，可在设置改绑，改绑后的旧键不再生效。

自动回归：`node scripts/test-hotkeys.mjs`。覆盖默认绑定及作用域冲突、用户自定义优先、显式解绑、旧配置补齐、无效导入值、停用动作，以及输入法/输入框/重复按键/弹层保护。类型验证：`npx tsc --noEmit`。

桌面验收：在空白画布分别按六组键；打开设置/灯箱后按新增键和 Delete，确认不触发背后动作；选择图片组和生成结果，按 Ctrl+Shift+I 核对助手附件；改绑、解绑后导出导入配置并重启，核对保留。启动 ComfyUI 的真实服务可用性需在已配置桌面环境单独验证，自动回归不启动服务。
