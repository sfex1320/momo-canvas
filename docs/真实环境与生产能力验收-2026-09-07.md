# 真实环境与生产能力验收 · 2026-09-07

本报告承接「改造收尾验收」末尾的未验收项。下列结果区分真实服务调用、桌面实际操作和受控回归，不把模拟通过写成服务商实测。没有打包发行版；当前开发应用已更新并重新打开。

## 已补齐的实现

| 能力 | 入口和实际行为 |
| --- | --- |
| 精细元素蒙版 | 元素工坊 → 精细蒙版。U2NetP 识别主体，绿色保留笔、红色删除笔通过 OpenCV 精修；保留原始 RGB，支持此前蒙版续修、停止和关闭取消。蒙版随元素保存，修改裁切范围会使旧蒙版失效。 |
| 平面正面、背面、底面 | 选择一个视图分别出稿，明确禁止折纸展开图和多面混排。背面、底面的指定颜色由本地像素合成落实；宽高、毫米、DPI、背景仍由用户控制。补上低透明度色键残留清理。 |
| GLB 骨骼动画 | 3D 预演 → 关键帧与轨迹 → 骨骼动画与姿态。播放模型自带动作、调整速度/循环，逐骨骼 XYZ 旋转，记录/删除姿态关键帧；支持时间轴往返采样。每个实例使用独立骨骼和混合器，归一化不覆盖动画根变换。 |
| CMYK 输出 | 设计工具 → 印刷与精细生产。选择印厂 ICC，把尺寸画板转为真正的 CMYK TIFF，嵌入 ICC，保留 DPI 和像素尺寸。RGB 配置文件会被拒绝。 |
| 毫米刀线 | 同一生产页导出所选透明元素的 SVG，沿 alpha 边界生成闭合轮廓并保留孔洞；使用毫米和 CutContour 分组。增加噪点轮廓复杂度上限。 |
| 无损局部替换 | H3 导演台 → 局部重做与版本对照 → 原码流无损拼接。FFmpeg stream copy，保留原 Take；校验编码、音轨、时间基、关键帧切点和输出时长。不能无损连接时明确报原因，不静默重编码。 |
| 大画布 | 超过 250 节点只渲染当前视口；超过 2000 节点的小地图默认收起，可手动打开。关闭/切换画布时清理延迟适应视图任务。 |

生产环境复用了本机已存在的 Python、Pillow、OpenCV、rembg 和 FFmpeg。U2NetP 约 4.6 MB 的模型缓存写入 MOMO AppData，不更改 ComfyUI 工作流。Python/FFmpeg 路径已通过界面保存。用于验收的 SWOP ICC 已清空选择；实际生产应选择自己的印厂配置。

## 本轮实际发现并修复的问题

1. 语音录音停止后，最后一块 `dataavailable` 尚未到达就提交了音频；改为等待实际 stop 回调。
2. 挂断后的迟到识别回填草稿、重复申请麦克风、迟到设备未释放；增加通话代次、取消信号和等待释放。确认卡等待也能退出，避免语音轮次卡住。
3. Windows 原生 Python 子进程对中文路径使用了错误编码；统一 UTF-8，原生中文文件导出已实测。
4. 首次真实元素出稿把正面画成展开盒、背面混入底面；收紧单面提示词并落实背底颜色，第二批真实生成已改善。
5. 3D 无动画加载数据缺省时克隆失败；动画列表缺省为空。异步加载后删除实体的回归通过。
6. 当前默认视频模型误选 `doubao-seed-2-0-lite-260215`。Seed 理解模型与 Seedance 视频模型用途不同；运行前和设置添加入口增加阻断提示。默认项改为同一服务商中已有的 `doubao-seedance-2-0-260128`，协议和密钥保持原值，原配置在 AppData 留有备份。此配置修正不代表该服务商视频协议已经实测通过。
7. 刀线成品尺寸原先包含透明留白，造成实际轮廓小于输入尺寸；改为按轮廓外接框归一化。带留白与孔洞的数值测试通过，真实透明稿重放生产函数后外轮廓严格覆盖 0,0 到 600,400 mm，样本为 `原生刀线-成品尺寸.svg`。

## 使用边界与尚不能签成通过的验收

- **真实语音服务**：当前没有配置 ASR/TTS 模型，已询问所用服务商和模型，尚未收到信息。录音生命周期和请求链有回归证据，但无法把未配置的真实识别/播报写成通过。
- **所有服务商和所有重型工作流**：本轮真实验证当前对话、绘画和一条本地 Comfy 链路；其它协议有请求构造测试。没有逐家付费生成视频，也没有把每个 H3/Comfy 模型工作流跑完，不能宣称全服务商认证。
- **长时间性能**：完成了 5000 节点和五分钟持续检查；不是数小时/数天运行或堆内存泄漏认证。构建仍有大于 500 KB 的入口和 Three 块告警，以及部分混合导入提示，未隐藏告警。
- **语义分层**：可对识别出的元素区域做主体蒙版及手工精修，不承诺自动恢复任意复杂设计的遮挡内容、字体或完整可编辑语义图层。透明轮廓是像素追踪，不自动生成刀具补偿、折线、连接结构或工艺公差。
- **骨骼能力**：已支持带骨骼 GLB 的动作和姿态关键帧；没有自动给无骨骼人物绑骨、IK 求解、动作重定向、口型或布料模拟。
- **不可见面和衔接质量**：背面/底面由模型推定，工程尺寸由用户输入；视频无损模式保持原码流，不自动制造视觉连续性。不同场景切换、遮挡细节、印刷校样仍需按具体作品判断。

真实样本、回归脚本与报告已留在项目中，付费验收代理和 Comfy 验收代理已停止，开发应用保持运行。
