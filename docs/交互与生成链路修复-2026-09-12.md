# 交互与生成链路修复（2026-09-12）

本轮按用户五张截图检查。截图里的界面文案仅作为问题证据。

## 已改动

| 问题 | 处理 |
| --- | --- |
| 生成状态文字贴边 | 图片节点状态增加内边距、居中与显式换行；Codex 分成生成提示、窗口说明并显示等待秒数。 |
| 内置角色预设库用途有限 | 删除弹层组件、样式、顶部入口和运行时状态；停用旧快捷键。项目人物素材及角色卡继续保留。 |
| 开始菜单快捷方式解析失败 | 使用 Windows Shell 解析真实 `.lnk`，保留目标、参数和工作目录。HTML 拖入的链接字节保存到应用快捷方式目录，兼容没有 LinkInfo 的链接；字节不可读时按名称查开始菜单。 |
| 软件图标始终是播放符号 | 提取系统软件图标，旧快捷方式打开资产库时补齐并持久化；读取失败保留通用图标。 |
| Photoshop 报 `Not allowed to open path ... with ...` | 原因是 `plugin-opener.openPath(asset, program)` 的指定程序权限。改为受控 Rust 命令调用 Windows Shell，文件路径作为单独参数，支持空格和中文；资产右键菜单与拖到快捷栏共用该入口。 |
| 网站快捷入口 | 支持手填、拖网页链接或 `.url`。拖素材时打开网页并在资源管理器定位素材，提示在网页上传区完成上传。 |
| 电商切片转场生硬 | 规划阶段明确整张长图阅读流和相邻边界契约；逐片生成投喂上一片底部 18% 裁条，单片重生另带下一片顶部裁条。提示词区可编辑上下接缝计划，改一侧同步到相邻切片对应侧。提示词输出模式跟随用户修改后的切片；缺片禁止跳过拼接。 |
| 创作助手改图失败后长时间生成 | 参考图读取设 60 秒超时；前端整次等待上限 11 分钟；后台图片排队上限 60 秒、执行上限 600 秒；已回传图片只等 20 秒收尾，不因结束通知丢失丢图。旧会话恢复失败时，仅在提交新一轮前用真实参考图建立新会话。 |
| 助手失败后继续生成 | 发现失败分支把错误反馈给模型后可能沿用旧确认重试。图片和视频均改为失败清确认并结束本次执行。 |
| 画布再次生成缺少改图依据 | 助手本次参考图物化为冻结的图片源节点并连线，画布重试沿同一输入链执行，不重新运行旧生成节点。 |
| Codex 创作按钮没有反馈 | 该按钮原本只是切换模型和模式，不是另一个面板入口。增加选中态、提示并聚焦输入框；设置卡“打开助手”和此按钮共用原子选择函数。 |
| Codex 设置卡过长 | 常驻标题、打开助手、展开入口；其余信息收进悬浮抽屉，移出收起，支持 Esc。 |
| 深邃黑预览停留在暖橙 | 预览直接复用深邃黑主题令牌作用域；名称改为石墨灰白，图标也同步调整。 |
| ComfyUI 总提示装桥 | 区分已安装文件与在线启用状态，安装路径持久化，升级前已装的桥会从来源目录向上查找认领。离线不会要求重复安装。 |
| ComfyUI 未启动却显示在线 | 来源“在线”实际是文件系统可读，现改称“目录可读取”。服务连接由共享 `/system_stats` 探活维护，5 秒超时、15 秒周期和窗口 focus 刷新；地址改变清掉旧状态，旧地址的迟到响应不能覆盖新状态。 |
| 设置、同步和启动分散 | 同步中心加入 ComfyUI 设置入口；设置页保留同步入口。三个入口共用启动配置和状态；顶部、设置、同步中心均有一键启动按钮。首次绑定 exe/bat/cmd/lnk，后续复用。远程地址不启动本机程序。 |
| 本项目按钮点不了、素材杂乱 | 普通画布显示“本画布”，导演台显示“本项目”；新资产记录画布归属，旧生成资产按节点归属回退。同生成组、同片段、同节点以及同日同类型导入素材自动折叠，保留逐项显示。仅改变视图，不覆盖人工文件夹和标签。 |

## 能力边界

- 普通超链接不能直接操作任意网站的上传框。真正自动上传需要目标网站接口或浏览器扩展适配；本轮没有把“打开网站并定位文件”描述为上传成功。
- `dragDropEnabled=false` 的 WebView2 HTML 拖放仍不能保证提供任意 exe/文件夹的绝对路径。已有路径、Shell 链接及能唯一匹配开始菜单的程序可识别；其余走“选择启动文件”明确绑定，不能靠同名文件猜磁盘位置。商店虚拟入口也不能承诺与普通 `.lnk` 等价。
- Photoshop 的权限报错调用点已替换，系统链接与路径测试通过；未声称实测了该 Photoshop 安装实例内部成功加载素材。
- ComfyUI 启动器可能先打开它自己的启动面板。MOMO 只在服务探活成功后显示连接，120 秒未就绪会提示检查启动器。未在本轮替用户选定或运行具体 ComfyUI 启动器。
- 电商接缝新增了实际图片约束，尚未用用户那套电商素材生成整套长图做视觉验收；图像模型仍不能保证像素级无缝。
- 截图中的历史超时请求未直接复现。此次确认并修复了无界参考图读取、失败后循环请求、结果收尾等待和重试丢参考图等具体路径，真实两轮续接成功。

Codex 协议核对：本机 app-server schema 与 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。`excludeTurns` 只控制恢复响应的历史返回量，不是丢弃模型会话历史，因此没有把它当成改图失败根因移除。
