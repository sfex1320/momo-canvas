# 平面总稿、H3 双语写作与灰白主题

本次按最新说明修正了“元素拆解”的产品含义。保留原有抠图能力，另建效果图平面化入口；没有把裁切原效果图当作平面化。当前为开发版更新，未打包发行版。

## 两套独立流程

| 名称 | 实际行为与入口 |
| --- | --- |
| **效果图转平面总稿** | 图片编辑菜单 → 效果图转平面总稿。输入立体效果图、编辑提示词、选择绘画模型和目标像素尺寸，一次生成一张完整平面部件总稿。要求去透视、去厚度阴影、部件完整分离、保留原色和可辨认文字。原效果图保留，结果独立落画布并收进资产库。 |
| **元素抠图与分层** | 图片编辑菜单 → 元素抠图与分层。视觉识别后核对框选，保像素拆件或勾选模糊件进行高清重绘，输出透明部件并按原位建组；仍支持手工圈选与精细蒙版。 |
| **单件视图重绘** | 原有正面、背面、底面推定改用此名称，包括对应颜色和尺寸设置。旧技能 id 保留，避免已有绑定失效。它不再与新平面总稿使用相同名称。 |

新总稿面板提供“转为真正 SVG”和“原图拆件 / 模糊件重绘”。SVG 通过现有本地矢量节点的路径描摹生成；拆件处理的是新平面总稿。绘画模型返回的是栅格图片，不将“矢量风格”冒充 SVG。独立部件仍可通过各自的矢量节点转 SVG。

“圆柱拆解”本轮按“原图拆件”处理；尚未收到对圆柱曲面展开的确认，因此没有另建圆柱工程展开算法。

新增内置 Skill：**效果图转平面总稿**。提示词可直接编辑。生成前显示模型与估价，关闭、停止、切换画布或删除源节点后，迟到结果不会重新插入当前画布；已经返回且保存成功的付费图片仍保留在资产库。

目标像素尺寸受模型支持范围约束；毫米、DPI、背面/底面颜色继续使用原有生产/单件重绘工具。遮挡内容、不可辨文字和工程尺寸需要人工核对。

## H3 中文输入 → 排版 → 英文执行

入口：H3 工位 → 片段检查器 → 提示词 → **中文写作 → Skill 排版 → 英文执行**。

1. 输入中文文案和补充排版要求；长期规则可保存为 Skill 并绑定项目。
2. 按配方引擎、模型规则选择生效的 Skill。排除剧本规划、项目包、纯校验和制图方言，避免规范混入。
3. 一次生成中文排版稿和英文待审稿。Base 模式为三段，Ref2VA 为六段；描述译成英文，对白、歌词和可见文字要求保留原语言。
4. 两稿可对照修改，点击“核对并采用英文执行稿”时再次校验，再写入执行稿。不会生成后直接覆盖已锁定稿。

新增内置 Skill：**H3 中文排版与英文执行**。无需绑定也有内置基本格式规范。对白取片段对白列表；中文输入明确使用 `<d>原文</d>` 时以标记内容为准。

校验覆盖字段完整性、顺序、空小节、逐字对白、真实素材编号、中英文参考一致性、镜头范围一致和总时长。生成或采用期间修改中文、规则、素材或执行稿，会拒绝过期结果。语义翻译仍需对照审阅，结构校验不能保证任意文案“完美翻译”。

本次额外修复：

- Base 三段式成品稿不再被项目风格/通用负向重新包裹，保持英文执行稿原文。
- 运行期素材说明写进 Base 的画面小节，保持字段结构。
- 首帧/尾帧对齐检查识别英文 `first frame` / `last frame`。
- 声场和配乐可以与镜头并行，不能把它们的时间标记当成重复镜头。真实模型测试暴露了这一误报，已修复。

## 外观与交互

- 深邃黑采用中性黑灰底色和灰白强调色。常用图标为白色，主按钮、图标底板和 Logo 使用轻微石墨渐变。
- 资产库“本项目”并入顶部 **全部资产 / 本项目** 分段按钮，明确当前选中状态，保留项目切换后的筛选语义。
- 警告、错误及 3D 坐标轴的数据色继续表达状态，不使用强调色替换它们。
- 总稿弹窗的操作区保持在滚动底部，减少长提示词遮住生成按钮的问题。

## 下一步值得增加的能力

本次查阅的 Lovart 官方资料强调可编辑画布、文字编辑和元素级调整：[工作方式](https://www.lovart.ai/docs/getting-started/how-lovart-works)、[高级编辑](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing)。对 MOMO 的具体建议如下；这是优先级建议，不将它们记成已实现功能。

| 优先级 | 建议 | 对当前美陈/文化墙工作的价值 |
| --- | --- | --- |
| 高 | 独立文字层、字体匹配/替代提示、OCR 原文校对 | 模型出稿后直接改错字和日期，减少整张重生。比单纯继续增加生图按钮更有价值。 |
| 高 | 部件清单与生产尺寸联动 | 每块记录名称、数量、毫米尺寸、材料、厚度、正背面，导出统一部件清单，减少拆件后人工对账。 |
| 高 | 项目术语与人名中英对照表 | 同一人物、地点、道具跨段使用相同译名；双语稿修改时展示差异，降低连续镜头漂移。 |
| 中 | 多尺寸版式变体 | 利用现有画板和品牌规则生成横版、竖版与印刷版，并显示超出安全区的文字/图片，减少逐画板调整。 |
| 中 | 统一运行前检查 | 在一次检查中报告缺少模型、参考离线、尺寸超限、未采用稿和成本，让修复入口直接指向问题，减少跨页面找设置。 |

## 尚未完成的外部验收与边界

上一阶段证据详见[真实环境与生产能力验收](真实环境与生产能力验收-2026-09-07.md)。真实连续第二张图、原生导出/恢复、基础 Comfy 链路、生产能力和 5000 节点短时测试已有证据，未因本次改造撤销。

- **真实 ASR/TTS**：仍缺用户配置的识别和播报模型，不能将真实语音全链路写成通过。
- **全部服务商/重型工作流**：没有逐一付费跑完每家视频服务和每个 H3/Comfy 工作流；不是全协议认证。
- **复杂作品质量**：本次真实平面化样本是单个立方体，多部件拆分有受控回归；复杂文化墙、遮挡补绘、文字准确度和工程尺寸尚需具体作品验收。
- **性能**：已有 5000 节点和五分钟检查，不等于数小时持续运行或泄漏认证；打包告警尚存。
- **更深层能力**：自动恢复任意语义图层、无骨骼角色自动绑定、IK/动作重定向、自动刀具补偿等未实现，不以现有蒙版、骨骼姿态或 SVG 轮廓替代这些承诺。

因此可以交付本次明确的两套工作流、双语编辑和主题改造，但不能把上述未配置、未实测或更深层能力一并写成“全部完成”。
