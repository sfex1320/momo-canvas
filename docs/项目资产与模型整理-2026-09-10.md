## 2.5 的型号、质量与价格

Flare 与 Sunburst 是两个型号，分别偏向快速创作与复杂创作；它们均有 auto、low、medium、high、xhigh、max 质量档位。质量和型号不是同一概念。软件按具体版本显示四档或六档，中文文案统一。

当前 65535/APIMart 内置自定义模板未引用 quality；这些入口的质量按钮禁用，并明确提示按型号生成。未经站点文档或请求验收，不擅自给逆向协议新增参数。

官方按输入/输出 token 计费；中转站可能按次、尺寸、套餐或渠道计费。OpenAI 官方价格不等于中转站最终扣费。Grsai 官网当前目录显示通用 2.5 为每次 600 积分、两个具名型号为 3000 积分，人民币换算依页面选择的充值套餐变化；实际价格仍应以账号账单为准。

## 本地高清的选择

用户说的组合方式通常叫“模型集成”或“分区融合”。目前 MOMO 已有主超分模型、可选细节模型、去压缩、人脸局部处理、硬边保护与颜色保真校正，属于组合管线；不是每次都把所有模型跑一遍。

| 内容 | 更合适的处理方式 |
| --- | --- |
| 纯色块、Logo、文化墙 | 色盘与轮廓校准 → 几何/矢量重建或保守重采样；避免整图增强纹理 |
| 照片 | NomosWebPhoto 作为现有基线；HAT 的保真权重、SwinIR 作为下一轮候选对照 |
| 照片 + 字体 + 色块海报 | 照片区域超分，文字/硬边区域单独保护或重建，然后原位合成 |

不要简单串联三套锐化模型，也不能把不同架构的权重直接平均。现有代码的神经计算长边预算为 6144；更大的最终输出可能包含重采样阶段，因此“导出 8K”不等于全流程按 8K 神经计算。此前合成样例中两份裸超分权重出现边缘亮圈；尚无用户当前问题原图，不能据此确定其具体马赛克原因，或宣称新模型必然更好。

完整型号、许可、实测和来源见[矢量与本地放大选型](./矢量与本地放大选型-2026-09-10.md)。本轮没有更换已安装权重，也没有接入被用户排除的分层模型路线。
