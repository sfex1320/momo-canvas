# 创作链路与导演台写作改造

## 使用入口

- 设置 → Codex 会员 → **用于对话与生图**：让默认优化、识图、剧本分析走 Codex。节点仍可各自选模型。
- 创作助手 → **Codex 创作**：同时选择 Codex 对话与生图，切到可执行画布动作的创作模式。文件任务保留独立目录选择与停止功能。
- 切片工作台：卡片只显示缩略图、标题、两行摘要；**调整**打开草稿弹窗，可手改、优化、精简、翻译、自定义指令，保存后生效。
- 独立“平面设计工作台”入口移除，旧品牌数据保留。

## 导演台流程

1. **剧本库**：继续支持大纲、完整剧本、分段稿与成品提示词包导入；用户已有稿件保留原文。
2. **素材定义**：人物、场景、道具分类。拖入、粘贴或选择图片时按文件名建立定义；也可追加参考图、绑定已有资产、用视觉模型填写名称与定义。角色与音色档案仍可进入。
3. **分段编写**：勾选出场素材；填写动作、表情、交互与机位；时间可用 `2.501s`、`2501毫秒`、`00:02.501`，储存到秒的小数部分，显示三位毫秒标签。支持识别时间行并追加；显示重叠、空隙、超出时长的问题。
4. **生成选片**：沿用现有真实生成队列、参考槽、配方、版本与采用流程。写作页可以准备中文稿，再由已有 H3 写作工具排版翻译，核对后采用。旧最终执行稿不会被写作编辑静默覆盖。
5. **初剪交付**：复用裁剪、音量、淡化、转场、字幕与 MP4 渲染；新增配乐上传、按角色记忆音色的 TTS，以及从指定时段提取视频或声音参考。提取结果入库并绑定紧邻下一段。

七个工位标识与已有项目数据保留，主导航按导入、定义、编写、生成、初剪排列，制图与 MV 仍可直达。

### 连续性与文字的实际含义

- 同场景自动接力：比较相邻片段所选场景定义；没有定义时按场景 id。首段不接力，硬切不投喂历史桥接槽。
- 选择素材会进入统一 `effectiveSlots` 与提示词编译；未选角色不会因旧代词兜底进入新编写片段。
- 已完成 H3/最终执行稿仍按原文发送。修改素材定义后应重新准备和审阅执行稿。
- 毫秒是写作精度，视频模型支持的生成时长仍受协议能力约束，导出到基于帧的 XML 时会按帧率量化。
- 固定 TTS 音色 ID 与音频参考不是自动声音克隆。普通 TTS 不接受参考录音；参考音频供支持它的视频模型使用。

## Eagle 离线队列

离线、超时、Token 失效只保留连接状态与待传队列，不弹逐素材离线错误。重连按 30 秒间隔退避；单个素材重试次数不因离线增加。重新登录连接成功会恢复全部待传，仍按两路并发依次入库，完成后汇总提示。重启后从资产账本恢复 queued/pushing/local-dirty/连接失败 offline 项；远端已删除或被新版本接管的素材不会当成待上传。

## 剪辑工程导出

- **PR 工程**：FCP7 XML + 原素材副本 + SRT + 时间线参数。保留片段顺序、入出点、原声与分离音轨、音量。转场、淡化、旋转、镜像与标题卡需在 PR 重设；完整参数仍保留在 JSON，MP4 导出照常应用效果。
- **剪映草稿**：使用 `pyJianYingDraft 0.3.0` 生成实际 `draft_content.json` / `draft_meta_info.json`。支持时间范围、音轨、字幕、音量、淡入淡出、叠化、旋转与镜像。选择剪映的草稿根目录，重新打开剪映查看。标题卡需在剪映补排。
- 两种导出均新建独立目录并复制素材，不覆盖已有项目。不生成伪 `.prproj` 扩展名。
- 本机已安装隔离 Python 环境于 `tools/jianying`，开发环境自动探测；发行版可在 **剪映环境** 选择已安装该包的 Python。第三方依赖不进入代码仓库。

参考：[Adobe XML 交换说明](https://helpx.adobe.com/premiere/desktop/render-and-export/export-files/export-a-project-as-a-final-cut-pro-xml-file.html)、[pyJianYingDraft 源码与兼容矩阵](https://github.com/GuanYixuan/pyJianYingDraft)。草稿生成与在特定 PR/剪映版本中打开是两项验收，本轮未操纵这两款桌面编辑器。

## 验收记录

- TypeScript 与前端生产构建通过。
- Codex Rust 权限/取消/结果校验 4 项通过；真实会员视觉调用能识别人工红蓝图，遵循应用 system 并返回 image 动作 JSON。
- 隔离浏览器验收包含毫秒解析、时间行识别、按段素材/提示词、接力策略、Codex 视觉能力、XML 编码及解析、离线重试保留。实际点击检查了时间标签和切片弹窗保存。
- `scripts/qa/workflow-native.py` 使用人工生成视频与音频，6 项断言验证剪映裁剪、时间位置、音轨、字幕、总时长与防覆盖。没有读取真实用户工程。
- PR 与剪映实际导入效果、真实角色配音音色与用户项目的生成质量仍需在对应软件及素材上验收，不能由文件结构校验替代。
